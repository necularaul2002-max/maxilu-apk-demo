# MAXILU APK — Feature Map

This page separates the mobile application's documented feature areas from what is actually included in this public demo repository.

| Area | Private V10 project | Public demo |
|---|---|---|
| Native Android UI | Implemented in private app source | Selected Java UI components and XML resources |
| Bottom navigation | Implemented in private app source | Navigation presentation source |
| AI model selection | UI and Gateway workflow documented in V10 | High-level description only |
| Chat and task status | Implemented in private app source | Not included as a complete runnable feature |
| Gateway communication | Private client and protocol implementation | Architecture boundary only |
| Device pairing and sessions | Private implementation | Excluded |
| Approvals and permissions | Private implementation | High-level description only |
| Notifications | Private implementation | Excluded |
| APK installer | Generated by CI when a valid build runs | No APK currently published |

## Important

A feature listed under the private V10 project is not automatically available in this public repository. The public demo is a curated portfolio extract, not a complete clone or release package.
