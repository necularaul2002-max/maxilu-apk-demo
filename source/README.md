# Selected Android source excerpts

This folder is intended for selected, non-confidential source files copied from the private MAXILU APK V10 project.

The public selection focuses on Android presentation code and visual resources. It excludes the complete app, MainActivity, Gateway clients, pairing/session code, credentials, private protocol contracts, signing configuration and internal CI configuration.

## Build status

This folder is a portfolio source extract. It is not a standalone Android Studio project and cannot be built by itself. The complete build configuration and dependencies remain in the private repository.
